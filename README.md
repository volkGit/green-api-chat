# 📱 Chat Application

Современное веб-приложение для обмена сообщениями, построенное на React с использованием Feature-Sliced Design.

С использованием сервиса GREEN-API `https://green-api.com/`

## 📋 Требования

- **Node.js** версии `v24.13.0` или выше

Проверить версию Node.js:
```bash
node -v
```

## 🚀 Установка и запуск

### 1. Установка зависимостей

```bash
npm install
```

### 2. Локальный запуск (режим разработки)

```bash
npm run dev
```

После запуска откройте браузер по адресу, указанному в терминале (обычно `http://localhost:5173`).

## 📦 Сборка проекта

Для создания оптимизированной production-сборки:

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`.

Для предпросмотра production-сборки локально:

```bash
npm run preview
```

## 🛠 Доступные скрипты

| Команда | Описание |
|---------|----------|
| `npm run dev` | Запуск dev-сервера с hot reload |
| `npm run build` | Сборка production-версии |
| `npm run preview` | Предпросмотр production-сборки |
| `npm run lint` | Проверка кода линтером |

## 📁 Структура проекта

Проект построен по методологии **Feature-Sliced Design (FSD)**:

```
src/
├── app/          # Инициализация приложения, провайдеры, роутинг
├── pages/        # Страницы приложения
├── widgets/      # Самостоятельные блоки UI
├── features/     # Функциональность приложения
├── entities/     # Бизнес-сущности
└── shared/       # Переиспользуемые компоненты и утилиты
```

## 🔧 Технологии

- **React** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **TanStack Query** — управление серверным состоянием
- **Zustand** — глобальный стейт
- **SCSS Modules** — стилизация
- **Feature-Sliced Design** — архитектура
